The ThinkCentre M710q (2017, Core i3-7100T, two cores / four threads) boots the firmware from a USB stick; there is no operating system.
Attis 27B, three fixed prompts x 32 greedy tokens, median decode seconds per token:
- first port (15 Nov): 0.848 s/token
- kernel update: 0.787 s/token
- compiled engine, parameters from the board's own sweep: 0.521 s/token
- the same firmware with a second memory module (dual-channel): 0.344 s/token (before 0.515); first token 5.77 s on a sustained 64-token run
Every step gave the same text on the three prompts.
Long prompt (3076 tokens): same text from the reference and compiled engines; 972 s against 1189 s with attention heads on all four cores.
Own network driver: 1.55 µs per frame sent against 36.7 µs through UEFI's driver.
Integrated GPU (Intel HD 630): first command executed under the firmware, a value written and read back.
