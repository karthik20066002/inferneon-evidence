Language models on a Raspberry Pi and a 2017 office PC, with no operating system

InferNEON is firmware, built in this project, that boots an 8 GB Raspberry Pi Compute Module 4 (four Cortex-A72 cores at 1.5 GHz) straight into a language-model server. There is no Linux underneath: networking, storage and model execution all run bare-metal. The same firmware boots a 2017 Lenovo ThinkCentre office PC from a USB stick. Four models have answered on the CM4; the boards’ answers match reference models word for word, and the Lambda Engine now builds a model’s engine from its published files and serves the same answers on both machines.

Timeline

Three weeks of measured milestones

  1. 3 Nov
    Bare-metal Ethernet on the board

    70,000 exact UDP echoes in 12.12 s, payloads up to 1472 bytes. C05

  2. 4 Nov
    First answers over HTTP

    Four HTTP 200 replies ("Hi") from the 27B model; a repeated request fell from 565.37 s to 269.08 s between two builds. C11

  3. 6 Nov
    A 32-token streamed answer from the 27B model

    3.814 s per token; first token after 82.24 s. C12

  4. 11 Nov
    Later 27B build

    3.584 s per token over a 44-token answer; first token after 82.4 s for 42 prompt tokens. C13

  5. 11 Nov
    Second model on the board: Gemma 3 1B

    0.36 s per token; a follow-up turn reused 26 of 40 prompt tokens. C14

  6. 12 Nov
    Third model: Gemma 3n E4B

    1.66 s per token. Drafting with the 1B model measured slower (1.95 s), so it is off. C15

  7. 12 Nov
    NVMe drive driver

    The 8.60 GB model copied once from SD to NVMe in 477 s, then loads at 57 MB/s with every byte checked. C16

  8. 12 Nov
    Fourth model ported: LFM3-1.7B

    Matches reference implementations off-board. C17

  9. 15 Nov
    A 2017 office PC boots into the firmware

    The ThinkCentre M710q runs Attis 27B from a USB stick, no operating system: 0.848 s per token. C20

  10. 16 Nov
    One model on two machines

    The ThinkCentre and the CM4 serve Attis together, layers split between them: the same text as one board. C22

  11. 17 Nov
    The office PC at 0.344 s per token

    Compiled engine and dual-channel memory; the same text at every step since the first port. C20

  12. 18 Nov
    Integrated GPU first light

    A first command executed by the ThinkCentre’s integrated GPU under the firmware. C23

  13. 20 Nov
    The Lambda Engine verified

    20 published checkpoints matched to Hugging Face transformers in every layer. C24

  14. 22 Nov
    LFM3-1.7B answers on the CM4

    0.584 s per token on three prompts. C18

  15. 22 Nov
    Generated engines on both boards

    One LFM3 container on the CM4 and the ThinkCentre: identical answers on ARM and x86; 0.111 s per token on the ThinkCentre. C26

Builds changed between milestones. No step is a matched before/after experiment, so no speed change is attributed to a single cause.

Not proven

What this evidence does not show

  • Answer quality on an independent benchmark. The reference checks show the board computes the same text as the reference model; they do not grade the answers.
  • Repeatability. Most rows are one run on one board, with no confidence intervals.
  • Energy use, temperature over long runs, or long-term reliability.
  • A speed-up from two boards together. The split is shown to give the same answers, not to be faster.
  • Model computation on the integrated GPU. Only a first command has run there.
  • Any cost or energy advantage over other hardware, production use or interactive speed.
  • The cause of any build-to-build change.
  • Original pretrained models. Attis is adapted from a third-party base model; Gemma 3 1B, Gemma 3n E4B and LFM3-1.7B are third-party models that this project ported, not trained.
